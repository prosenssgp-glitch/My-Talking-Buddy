# Ishan AI Friend

A starter Android app for Ishan, a child-friendly learning companion. Includes spoken-English and math practice, Bengali prompts, text-to-speech, and microphone permission requested only when the user taps the microphone.

## Build APK
Open the repository's **Actions** tab and run **Build Android APK**. Download `Ishan-AI-Friend-debug-apk` from the completed workflow's Artifacts section.

This starter is a prototype: it does not include a connected generative-AI service yet. Camera is not used and no background recording occurs. Add an AI provider only after configuring a secure backend; never put private API keys in the app.
